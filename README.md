# Hi, I'm Pranav

I'm an Aerospace Engineering student at Georgia Tech interested in autonomous aircraft, flight controls, robotics, and experimental engineering.

I enjoy building systems that connect software to the physical world - from embedded computer vision and UAV avionics to test equipment, manufacturing tooling, and STEM education programs.

## What I'm working on

- Flight-controls and simulation work with the Yellow Jacket Space Program
- Propulsion test-stand systems with Georgia Tech Supersonics
- An eight-rotor omnidirectional UAV based on the PX4 DIY Omnicopter architecture
- Robotics and STEM-access programs through RAYSE-MN

## Selected experience

- Integrated AprilTag pose estimation on an Arduino Nicla Vision with a Cube Orange+ flight controller
- Built and tested autonomous UAV systems using ArduPilot, RTK GPS, MAVLink, and CAN avionics
- Designed and fabricated experimental fixtures for orthopedic biomechanics research
- Developed robotic tooling and manufacturing concepts for electric-vehicle production
